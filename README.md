# From Data Loggers to the Cloud

Slides from the ECU Department of Earth, Environment and Planning (DEEP) seminar, 2 October 2026, on the Environmental Sensing and Data Network (ESDN): an open-source LoRaWAN and ThingsBoard infrastructure for environmental sensing in eastern North Carolina.

**View the slides:** https://boris-edu.github.io/esdn-deep-seminar-2026/
**With speaker notes:** https://boris-edu.github.io/esdn-deep-seminar-2026/?notes

Paper: Dessimond, Moysey, Finney, Howard and Manda (2026), *Frontiers in Water* 8:1906048, [doi:10.3389/frwa.2026.1906048](https://doi.org/10.3389/frwa.2026.1906048).
